### 2. Congiu & Moscati (2022) — *A review of nudges: Definitions, descriptions, and atmospheres* (Pages 188 à 213)
- **URL GitHub :** [02_Congiu_Moscati_2022_Nudge_Review_Texte_Integral.txt](https://raw.githubusercontent.com/P-s-y-e-n-c-e/psy7010/main/Quiz_et_Evaluations/Quiz_2_13oct_Commerce_Consommation/Audit_GPT/02_Congiu_Moscati_2022_Nudge_Review_Texte_Integral.txt)

### 3. BVA Nudge Unit — *A Brief History of Nudge*
- **URL GitHub :** [03_BVA_Nudge_Unit_Histoire_du_Nudge.txt](https://raw.githubusercontent.com/P-s-y-e-n-c-e/psy7010/main/Quiz_et_Evaluations/Quiz_2_13oct_Commerce_Consommation/Audit_GPT/03_BVA_Nudge_Unit_Histoire_du_Nudge.txt)

### 4. UX Researcher & Protocole de test utilisateur (Konrad & Nielsen)
- **URL GitHub :** [04_UX_Researcher_Konrad_Guide.txt](https://raw.githubusercontent.com/P-s-y-e-n-c-e/psy7010/main/Quiz_et_Evaluations/Quiz_2_13oct_Commerce_Consommation/Audit_GPT/04_UX_Researcher_Konrad_Guide.txt)
